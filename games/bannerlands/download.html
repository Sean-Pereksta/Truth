A shortcut straight to the battlefield.

  1. Open the downloaded installer. It creates a Bannerlands desktop icon and Start menu entry.
  2. Open Bannerlands, choose campaign settings, then select Host Lobby.
  3. Choose one to four human seats. Bots fill the other participating houses, up to sixteen in total.
  4. Share the guest invitation or list the lobby publicly. Once everyone has loaded the artwork and marked ready, start the match.

Friends can join the full game in Chrome or Edge without downloading anything.

A testing preview.

The host’s laptop must stay awake and connected. A closed or sleeping host ends the connection. Temporary public addresses change when hosting restarts.

Large campaigns are still being tested for smooth performance. Single-player remains available when online services are unavailable.

This preview installer is unsigned. The release page provides checksums for verifying the downloaded file.

Downloaded hosts and browser guests must use matching game and artwork versions. Host migration and multiplayer save/resume are not available in this preview.
