Every troop PNG has 4 equal columns by 2 equal rows (8 frames).
Top row, left to right: four walking-cycle poses.
Bottom row, left to right: four weapon-attack poses.
Sprites face screen-right; the game mirrors them for the other direction.
Each sheet depicts its own troop, equipment, silhouette and native house colors.

PROVENANCE AND USE
The new raster artwork was made with built-in image generation for this game. The existing troops-atlas.png and structures-atlas.png were used as style references so the new art fits the painted medieval RTS style.
The original common troop, structure and terrain atlases remain preserved.
Original generated PNGs are retained; the game reads the sprite grids and handles direction, animation and display size.
See house-art-prompts.json for the prompt set and source image paths. Each specialist has its own original PNG sheet; no common troop sprite is substituted for its house artwork.
All required PNGs are embedded when building the standalone Bannerlands.html, so play needs no external downloads.
