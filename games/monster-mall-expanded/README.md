# Monster Mall — After Hours / Expanded Edition

Survive the last night at Westbridge Mall: restore the power, evade evolving predators, and escape. Five difficulties add escape tasks and smarter monsters.

The playable entry is `index.html`, a self-contained HTML game with its runtime, artwork, and character models embedded. It supports keyboard/mouse, touch controls, and standard controllers. Click once in the game to enable sound.

Editable current source and the bundled Three.js runtime are in `source/`. Rebuild with `node source/build.mjs`; this regenerates `index.html`. Controls and survival tips are in `docs/`. Attribution and the Three.js license are retained in `credits/` and in the game. Duplicate unembedded model originals are excluded. Gameplay code and the playable HTML are unchanged.
