ACORN RALLY — PC EDITION

Keep one lobby running on a laptop

1. Extract the PC edition and open the server folder. Double-click
   "Start Acorn Rally Lobby.cmd" to start the supervised lobby server.
   Use "node server/lobby-supervisor.cjs" on macOS or Linux.
2. On each phone, open one of the "Phone lobby" addresses printed by the
   server, then tap Join lobby. The first player becomes the race host.
   Others join that room. The laptop runs the server and can sit out.
3. When the race finishes, join or ready up for the next race in the same
   lobby. If the host leaves, a connected player takes over. If everyone
   leaves, the next join opens a new room. Disconnected seats can resume
   for two minutes. Visitors can join a race between rounds.
4. Leave the laptop plugged in and awake. The supervisor restarts the
   server after an unexpected exit. Active races live in memory and end
   if the process restarts.

For Windows startup, schedule "Start Acorn Rally Lobby.cmd" to run at
logon in Task Scheduler. Add --no-open as an argument, set the Start in
folder to the extracted server folder, clear the execution time limit,
and choose "Do not start a new instance" for overlapping runs.
The laptop needs to be awake whenever players want to join.

Race on phones over Wi-Fi

1. Download the PC edition, extract the full ZIP, and double-click
   "Start Acorn Rally.cmd" from the extracted folder. The Windows
   launcher uses its bundled Node runtime when available. On macOS
   or Linux, install Node.js 18 or newer and run "node server/host.cjs"
   from the extracted folder.
2. Leave the host window running. Connect all phones to the same local
   network as the computer. The computer can use Ethernet on that network
   and can run the server without joining the race.
3. Open the "Phone lobby" address listed in the host window on one phone.
   The Windows launcher's Private Rooms screen also shows those addresses
   under "Play on phones." An example is http://192.168.1.20:8791/?room=join.
   If several addresses are listed, use the one for your shared network.
4. On that phone, choose Create room, select a course, and share the invite
   link. Each other phone opens the link and taps Join room. Players can
   also open the Phone lobby address and enter the five-character code.
5. Guests select Ready to race. The phone that created the room starts
   the race. Two to four phones can race together, with up to eight total
   players. Turn off Fill empty seats with AI for a human-only grid.
6. After finishing, return to the room and ready up for a rematch.
   Changing race settings resets guest readiness.

The room server runs on the local network. Once the package is on the
computer, a local race does not require an internet connection.

If a phone cannot reach the lobby

- Use the computer's local address with http:// and port 8791. The
  localhost address works only on the computer running the server.
- Check that the phone can reach other devices on the same network.
  Guest Wi-Fi and some hotspots isolate devices from each other.
- If Windows asks, allow the host on your private network. Keep the host
  window open while playing. Set ACORN_RALLY_PORT before starting the host
  if you need to use another port.

Solo play and split screen

Open index.html in a desktop browser for solo races, cups, Time Trials
or local split screen.

Sharing across networks

The host listens on TCP port 8791 by default. A private VPN shared with
your friends works across home networks. A publicly reachable reverse
proxy can also forward HTTP and the live event stream to this port.
Enable streaming without response buffering.

For access from outside your network, configure a named Cloudflare
Tunnel with rally.catnmice.com pointing to http://127.0.0.1:8791.
Use https://rally.catnmice.com/?room=join for guests. The game streams
race state with Server-Sent Events, so the tunnel must support SSE.
Cloudflare Quick Tunnels lack SSE support.

Optional Firebase listing

Run the public lobby first. To publish its join link, install firebase-admin
with "npm install --prefix server firebase-admin" in the extracted game
folder. Configure Application Default Credentials for the Catnmice Firebase
project on the laptop, set ACORN_RALLY_PUBLIC_ORIGIN=https://rally.catnmice.com,
and start the lobby launcher from that environment. For scheduled startup,
make the same settings available to the task's Windows account. Store
credentials outside the game folder. Configure one publisher for this
document, acornRallyService/public. It refreshes every 30 seconds and
expires 90 seconds after its last update. The lobby keeps working if the
directory is unavailable.

Connection recovery

If a browser loses its connection, an AI takes its place. The same browser
tab reconnects with its saved seat automatically. Refreshing the tab
restores the invite and seat as long as the host is still running. Use
Leave room when you are finished. In private room mode, inactive rooms
expire after 15 minutes.
Stopping the host window closes its rooms.
